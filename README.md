# 鱼雷双桌宠 Windows 版

> Windows 10/11 x64 重构版，Python + PySide6，提供安装版与免安装（便携）版。

把 [yuhanfu513-ops/leiyu-desktop-pets](https://github.com/yuhanfu513-ops/leiyu-desktop-pets) 的 macOS 双桌宠体验重构到 Windows：双透明置顶窗口、拖动、随机独白、靠近问答、逐句字幕、弹动与歪头、原声/1.5 倍氦气、**相声模式**、**火柴人躯体**、**像素级透明穿透**、**磨砂菜单与设置**、全局热键、系统托盘与开机自启。

## 下载与安装

从 Releases 下载：

- `LeiYu-Desktop-Pets-Windows-v2.1.2-x64-setup.exe` — 安装版，装到 `%LOCALAPPDATA%\Programs\LeiYuDesktopPets`，无需管理员权限；
- `LeiYu-Desktop-Pets-Windows-2.1.2-x64-portable.zip` — 便携版，解压即用，数据写在同目录 `data\`；
- `SHA256SUMS.txt` — 校验和。

> 安装包未做代码签名。
>
> **exe双击没反应？** 从网络下载的 exe 会被 Windows 打上「锁定」标记：右键 `exe` →
> 属性 → 常规 → 勾选「解除锁定」→ 应用，再运行。

数据目录：安装版为 `%APPDATA%\LeiYuDesktopPets`（配置、日志、导入素材）；便携版为 exe 同级 `data\`。
两个版本的设置项完全一致，区别只在数据目录位置。

## 功能

- 两只独立、透明、置顶、无边框窗口，可拖动；按 PNG alpha 命中检测。
- **绝对透明 + 像素级鼠标穿透**：主窗口不画任何底色，除了大头像素与火柴人线条
  其余区域 100% 透明；在 `WM_NCHITTEST` 里按像素判定，透明处的点击直接穿透到
  桌面或其它软件，落在人物/线条/气泡上才响应拖拽与单击。
- **火柴人躯体**（默认开，可关）：大头下面接一具代码绘制的火柴人，比例/线宽/颈部重叠/
  线条颜色可调；窗口向下加高而头像像素不变，位置锚在「底边中点」，开关躯体时脚不会跑出屏幕。
- **磨砂菜单与设置**：右键菜单、托盘菜单与设置窗口用系统 Acrylic 磨砂
  （Win10 1803+），不可用时退化为自绘半透明圆角底。菜单背板是自绘的玻璃面
  （渐变 + 顶部高光 + 底部内阴影），下拉框与子菜单的箭头是圆润的 chevron；
  设置窗口为无边框深色面板，五页全部按卡片分组，页签是胶囊分段控件。
- 单击某只桌宠只播放它自己的独白；「两人对话一句」由右键/托盘菜单触发。
- **相声模式**：严格按素材里的问答组成对交替（雷军问哪句、余承东就答那句），4/6/8/10/12 句可选。
- **决战模式**：相声的强度版，每句音量从 20% 阶梯升到 70%，且不会超过你设置的音量。
- 逐句字幕气泡，随音频进度同步；字号 9–20 可调。
- 靠近时互相歪头（距离可调），说话时轻微弹动；可开启「减少动效」。
- **十二款动作**：招手、跳舞、鼓掌、伸懒腰、鞠躬、托腮、原地跑、打瞌睡、踢腿、
  深蹲、比心、敬礼，空闲时随机播放（间隔 8–30 秒可调），右键「让 TA 做个动作」可手动点播；
  双击桌宠原地转一圈——
  默认是**原地转身（Y 轴翻转）**，转到侧面改用程序化侧影，不再被压成一条线（旧版风车滚转可在设置切回）。
- 原声 / 1.5 倍氦气两种配音，音量可调；窗口透明度 30%–100% 可调。
- **免打扰时段**：支持跨午夜区间，时段内不提醒、不弹气泡。
- **整点报时 + 久坐提醒**：静音气泡提示，久坐间隔 30/45/60/90 分钟可选。
- **番茄钟**：专注 15/25/45/60 分钟 + 休息 5/10/15 分钟，托盘/右键/设置均可启停；
  计时期间在窗口底部独立胶囊里每秒刷新倒计时——与对话气泡分开，说话和计时可以同时显示。
- **自动游走**：空闲时在屏幕内缓慢溜达，间隔可调；拖动或说话时自动让路。
- **自动移动后按概率对话**：游走停稳后按 0/25/50/75/100% 概率聊一段，模式可选相声/决战/随机，带 45 秒冷却。
- **对话开场决斗特效**：每场对话开头一次约 1 秒的「VS」特效，锁定两只头部中点缓动跟随；
  歪头、拖动、刚弹过提醒时自动跳过。
- **最近说过**：保留最近 8 条播放记录，托盘/右键一键重播。
- **重叠自动互喷**：两只拖到一起（脸部间隙 ≤24px，可调）即自动来一段问答，带冷却，默认关闭。
- **设置中心**（右键「设置…」或托盘「设置」）：声音、互动、外观、系统、关于五页，改动即时生效并落盘。
- **开机自启**开关在设置与托盘中都有，写入 `HKCU\...\Run`，免提权，卸载时清理。
- **全局热键**：`Ctrl+Alt+H` 显隐、`Ctrl+Alt+K` 相声模式、`Ctrl+Alt+R` 随机一句、
  `Ctrl+Alt+M` 静音/恢复、`Ctrl+Alt+X` 停止。
- **置顶开关**：可关闭「始终置顶」，让桌宠正常被其它窗口盖住。
- **记住位置**：退出时保存两只桌宠坐标，下次启动还原并自动夹回可见屏幕。
- **更新检查**：启动时查询 GitHub 最新 Release，发现新版本用托盘气泡提示（只提示，不自动安装）。
- **故障诊断**：`leiyu_pet.exe --selftest-audio` 检查音频解码后端并试播一段，输出 JSON。
- 日志滚动（512 KB × 3），未捕获异常写日志并弹托盘提示。
- 托盘菜单 + 右键菜单：显隐、播放、音量、距离、人物大小、声音模式、恢复位置、设置、退出。
- 单实例运行；重复启动会把已有实例带到前台。

## 从源码运行

```powershell
# 需要 Python 3.11 - 3.13
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -i https://mirrors.aliyun.com/pypi/simple/ -e ".[dev]"
.\.venv\Scripts\python.exe -m leiyu_pet
```
