# 验收清单

## 窗口与交互

- [ ] 启动后出现两只透明、置顶、无边框桌宠，背景完全透明。
- [ ] 可分别拖动两只桌宠；点击透明区域不触发，点击人物 alpha 区域触发。
- [ ] 主窗口除了大头与火柴人线条之外完全透明，没有任何底板、底色或窗口阴影。
- [ ] 在透明区域点击/右键会穿透到下面的桌面或软件；在大头、手臂、腿部线条上点击能拖动。
- [ ] 单击人物随机播放一段独白；右键弹出菜单。
- [ ] 两只桌宠靠近时互相歪头，距离可通过菜单/设置调整。
- [ ] 说话时头像轻微弹动，字幕气泡逐句显示并在结束后消失。

## 躯体、对话与面板

- [ ] 默认显示火柴人躯体；头部位置与大小与旧版一致，关闭后窗口回缩而脚不动。
- [ ] 躯体比例 / 线宽 / 颈部重叠 / 线条颜色改动立即生效，无需重启。
- [ ] 空闲时会随机招手或跳舞；间隔设为「关闭」后不再出现。
- [ ] 双击转圈转到侧面能看到侧影而不是一条线；设置切回「平面滚转」仍是旧版风车转。
- [ ] 自动游走停稳后按设置概率发起对话（0% 不触发），45 秒内不连发。
- [ ] 对话开头出现一次 VS 特效，约 1 秒淡出；拖动或歪头时不出现。
- [ ] 番茄钟倒计时显示在底部独立胶囊；说话与计时可同时可见。
- [ ] 右键菜单与设置窗口是磨砂玻璃（系统 Acrylic 或自绘半透明退化底），文字清晰可读。
- [ ] 设置窗口无边框、可拖标题行移动；关闭磨砂开关后菜单与设置恢复普通外观。
- [ ] 「让 TA 做个动作」子菜单里的十二款动作都能播放且轮廓互不相同。

## 播放与声音

- [ ] 大头、火柴人线条、气泡、状态胶囊都可以点击/拖动/右键；空白区域穿透到桌面。
- [ ] 原声模式播放 `Clips/` 音频；切换氦气模式播放 `Clips-helium/`。
- [ ] 音量菜单/设置滑块实时生效。
- [ ] 决战模式第一句就听得见（默认 65% 音量下约 36%），随后逐句渐强到当前音量。
- [ ] **捂嘴（禁言）**：开启后每只桌宠头上出现捂嘴大手；点击只回「已被禁言」；
      点播/相声/决战/互喷全部被挡下并弹「关闭捂嘴模式，快把我放出来」；
      不自动游走、不出 VS 特效、随机动作暂停；拖动仍可用；关闭开关立即恢复。
- [ ] 把两只拖到贴边会自动来一段问答（默认开启，12 秒冷却），设置页可关。
- [ ] 决战播放中拖动音量滑块，当前这句立刻跟着变。
- [ ] 停止播放可立即中断。

## 界面材质与布局

- [ ] 右键菜单是深色玻璃面板：圆角、上浅下深的渐变、顶部一道细高光。
- [ ] 菜单子项（挑一段 / 最近说过 / 番茄钟 / 音量 …）同样是玻璃面板，子菜单箭头是 chevron。
- [ ] 下拉框右侧是圆润 chevron，勾选框是蓝底白勾，没有实心蓝方块。
- [ ] 设置窗口无边框、可拖标题行；页签是胶囊分段控件；每页控件按卡片分组。
- [ ] 切换页签时窗口高度随内容收缩；内容超出时出现滚动条而不是把窗口顶出屏幕。
- [ ] 系统页的「恢复默认位置」「打开数据目录」是左对齐的普通按钮，不是整行宽的色条。
- [ ] 托盘提示、关于页、安装程序显示名都是「鱼雷双桌宠」。
- [ ] 设置窗口标题行只显示「设置 + 版本」，不重复产品名。

## 菜单与托盘

- [ ] 托盘图标存在，双击可全部显示/隐藏。
- [ ] 右键菜单 13 项以内、托盘 14 项以内：说一段、相声/决战、动作、音量、声音模式、
      番茄钟、设置、退出；不再出现「最近说过」「两人对话一句」「歪头距离」「人物大小」。
- [ ] 菜单每一项的高亮条撑满菜单宽度，短项（音量、声音模式）右侧不再有点不到的死区。
- [ ] 托盘与右键菜单用产品图标；托盘菜单每次弹出前勾选状态对齐当前设置。
- [ ] 设置面板改动实时生效并持久化到 `config.json`。
- [ ] 设置五页：声音（音量/声音模式/播放速度）、互动、外观（字幕与显示/火柴人/随机动作/材质）、系统、关于。

## 开机自启

- [ ] 勾选开机自启后，`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 出现 `LeiYuDesktopPets`。
- [ ] 取消后该项被移除。
- [ ] 若自启项被安全软件清理，启动时托盘给出提示。

## 单实例与数据

- [ ] 重复启动不会开第二个实例，而是把已有实例带到前台。
- [ ] 安装版数据在 `%APPDATA%\LeiYuDesktopPets`；便携版（含 `portable.ini`）数据在同目录 `data\`。
- [ ] 首次无素材时会弹出导入向导，导入后正常运行；选择“稍后再说”不崩溃。

## 发布产物

- [ ] 便携版 ZIP 解压后可直接运行，`data\` 自动创建。
- [ ] 安装器为 per-user、无需管理员，安装后桌面/开始菜单有快捷方式，可正常卸载。
- [ ] 卸载后 `HKCU\...\Run` 的 `LeiYuDesktopPets` 被清除。
- [ ] Release 含 setup.exe、portable.zip、SHA256SUMS.txt，校验和一致。
