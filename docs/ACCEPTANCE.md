# 验收清单

## 窗口与交互

- [ ] 启动后出现两只透明、置顶、无边框桌宠，背景完全透明。
- [ ] 可分别拖动两只桌宠；点击透明区域不触发，点击人物 alpha 区域触发
      （开着磨砂面板时，面板矩形内都可点/可拖）。
- [ ] 单击人物随机播放一段独白；右键弹出菜单。
- [ ] 两只桌宠靠近时互相歪头，距离可通过菜单/设置调整。
- [ ] 说话时头像轻微弹动，字幕气泡逐句显示并在结束后消失。

## 躯体、对话与面板

- [ ] 默认显示火柴人躯体；头部位置与大小与旧版一致，关闭后窗口回缩而脚不动。
- [ ] 躯体比例 / 线宽 / 颈部重叠 / 线条颜色改动立即生效，无需重启。
- [ ] 空闲时会随机招手或跳舞；间隔设为「关闭」后不再出现。
- [ ] 双击转圈转到侧面能看到侧影而不是一条线；设置切回「平面滚转」仍是旧版风车转。
- [ ] 自动游走停稳后按设置概率发起对话（0% 不触发），45 秒内不连发。
- [ ] 对话开头出现一次 VS 特效，约 1 秒淡出；拖动或歪头时不出现。
- [ ] 番茄钟倒计时显示在底部独立胶囊；说话与计时可同时可见。
- [ ] 关闭磨砂面板后只剩透明背景；圆角 0 为直角，改半径立即生效。
- [ ] 面板区域可拖动/点击，圆角处不留死区；开启鼠标穿透后整只不可点。

## 播放与声音

- [ ] 原声模式播放 `Clips/` 音频；切换氦气模式播放 `Clips-helium/`。
- [ ] 音量菜单/设置滑块实时生效。
- [ ] 两人对话一句会按 `pairs.json` 顺序播放问答。
- [ ] 停止播放可立即中断。

## 菜单与托盘

- [ ] 托盘图标存在，双击可全部显示/隐藏。
- [ ] 托盘与右键菜单均可：显隐、播放、音量、距离、人物大小、声音模式、恢复位置、隐藏当前、退出全部。
- [ ] 设置面板改动实时生效并持久化到 `config.json`。

## 开机自启

- [ ] 勾选开机自启后，`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 出现 `LeiYuDesktopPets`。
- [ ] 取消后该项被移除。
- [ ] 若自启项被安全软件清理，启动时托盘给出提示。

## 单实例与数据

- [ ] 重复启动不会开第二个实例，而是把已有实例带到前台。
- [ ] 安装版数据在 `%APPDATA%\LeiYuDesktopPets`；便携版（含 `portable.ini`）数据在同目录 `data\`。
- [ ] 首次无素材时会弹出导入向导，导入后正常运行；选择“稍后再说”不崩溃。

## 发布产物

- [ ] 便携版 ZIP 解压后可直接运行，`data\` 自动创建。
- [ ] 安装器为 per-user、无需管理员，安装后桌面/开始菜单有快捷方式，可正常卸载。
- [ ] 卸载后 `HKCU\...\Run` 的 `LeiYuDesktopPets` 被清除。
- [ ] Release 含 setup.exe、portable.zip、SHA256SUMS.txt，校验和一致。
